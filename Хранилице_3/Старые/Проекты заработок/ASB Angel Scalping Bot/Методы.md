Создать ордер на покупку
```
	r = cl.place_order(  
	    category="spot",  
	    symbol="BTCUSDT", #Символ монеты 
	    side="BUY", # купить или продать BUY SELL
	    orderType="Market", #тип ордера
	    qty=10, #количество монет (usdt)
	)
```

При продаже в аргументы метода place_order нужно передавать marketUnit, например:
```
r = cl.place_order(  
    ...
    qty=10, #количество монет (usdt)
	marketUnit="quoteCoin"
)
```
При этом в qty можно передавать количество usdt

Метод чтобы узнать информацию о паре
```
cl.get_instruments_info(category="spot", symbol="BTCUSDT")
```

В ответе 
```
'lotSizeFilter': {  
  'basePrecision': '0.000001', - точность для агрумента qty (в базовой валюте)
  'quotePrecision': '0.00000001', - точность при передачи в usdt
  'minOrderQty': '0.000048',  
  'maxOrderQty': '83',  
  'minOrderAmt': '1',  
  'maxOrderAmt': '8000000'  
},
```
