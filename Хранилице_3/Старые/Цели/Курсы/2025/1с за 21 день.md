### Резюме
==День 1==
Платформа - Средство для разработки
Конфигурация - программа для работа пользователей
Информационная база - То где хранятся данные о работе в конфигурации
==День 2==
Синоним - пользовательское представление данных
Имя - Идентификатор объекта. Можем обращаться из встроенного языка
Справочник - список объектов определенной структуры
Перечисление - фиксированный список элементов
Константа - условно постоянная переменная (Можно использовать в печатных формах)
==День 3==
Валовая прибыль это выручка - себестоимость
Операционная прибыль это Валовая прибыль - все операционные расходы
Чистая прибыль = Операционная прибыль - налоги,проценты по кредитам
Рентабельность отношение ВП к сумме отгрузки
С помощью журнал документов можно обхеденить разные документы в один список
==День 4==
в 1с 4 типа регистров: сведений, накопления, бухгалтерий, расчета
Регистры накоплений - для консолидации информации о хозяйсвтенных операциях. Нужны для быстрого формирования отчетов.
Запись в регистры делается при проведении документа
Регистр имеет структору:
Измерения - разрезы учета
Ресурсы - показатели(Числовые)
Регистр хранит информацию об ресурсах в разрезе измерения на любой момент времени
==День 5==
Регистры накопления: 
остатки - ресурс может увеличиваться и уменьшаться
накопления - только увеличивается
Регистр накоплений хранит фактическое значение показателя
В регистре сведений сведения могут браться от сотрудника например, а в регистре накоплений только от проведения документа. 
Можно задавать периодичность.
Подсистемы - отображаются в виде разделов конфигурации, можно сортировать в конфигураторе
==День 6==
программный код хранится в модулях.
Код нужен чтобы определить поведение модулей
Метод - это процедура
Сообщить("Вывод сообщения на экран")
Перем - определение переменной
Условные операторы:
Операции сравнения = >= > < <= <>
```
Если <Условие> Тогда
<Методы> 
ИначеЕсли <Условие> Тогда
<Методы> 
Иначе
<Методы>
КонецЕсли
```
Циклические операторы
Существует 3 вида циклов:
- Цикл по счетчику типа for
```
Для <Переменная> = <НачальноеЗначение> По <КонечноеЗначение>
Цикл
....
КонецЦикла;
```
- Цикл по выполнению условия
```
Пока <Условаия> Цикл .... КонецЦикла;
```
- Цикл по универсальным коллекциям

```
Для Каждого <НазваниеПеременнойКаждойСтроки> ИЗ <НазваниеКоллекции> Цикл

КонецЦикла
```


 
Ключевое слово Прервать в теле цикла завершает цикл
Ключевое слово Продолжить в теле цикла завершает текущую итерацию
==День 6==
Типы данных:
Строка Пишется в ковычках, есть конкотенация +
Число остаток от деления это %
Дата (Единое значение даты и времени) 
Можно получить текущую дату функцией ТекущаяДата(), можно прибавлять секунды
Булево Истина или Ложь можно инвертировать словом НЕ
==День 8==
Структура модуля
	описание переменных
	описание процедур или функций
	основной раздел
Процедуры и функции

Процедуры
```
Процедура <Название процедуры>(Параметры через запятую)
	Тело процедуры
КонецПроцедуры
```

В отличии от процедур, функции могут возвращать значение

Функции

```
Функция <Название функции>(Параметры через запятую)
	Тело функции
	Возврат <переменная>;
КонецФункции
```

Переменная объявленная в описании переменных, видна всему модулю

События
Перед - выполняется перед действием
При - выполняется после целевого действия

События документа
ОбработкаПроверкиЗаполнения - Позволяет проверить реквизиты документа
