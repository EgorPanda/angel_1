Core — фундаментальный координационный слой Angel AI, обеспечивающий общие механизмы взаимодействия компонентов, событий, разрешений и жизненного цикла операций. Core не содержит специализированную бизнес-логику отдельных модулей, а предоставляет инфраструктуру и правила, на которых они работают.
центральная оркестрационная часть системы, отвечает за жизненные цикл системы

Функции core
- опрос модулей системы
- запуск, перезапуск, остановка модулей системы
- взаимодействие с модулями
- Выполнение разных команд с разными модулями
- системные события;
- жизненный цикл операций;
- общие правила;
- маршрутизацию внутренних операций;
- интеграцию компонентов;
- единые системные механизмы.
