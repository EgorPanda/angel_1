Tools — контролируемый интерфейс возможностей системы, предоставляемый AI Agent. Tool представляет конкретную операцию, которую AI может запросить, например создание заметки или напоминания. Реализация Tool располагается рядом с соответствующим функциональным модулем, а регистрация, доступность и проверка разрешений управляются через AI Runtime/Core.

Например:

```
create_note
search_notes
create_reminder
send_notification
```
