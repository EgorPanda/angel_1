Модуль заметок
Заметки должны соблюдать иерархию объект -> объект.
То есть заметка может быть как родительским так и дочерним классом для другой заметки.
У заметок могут быть: теги, важность, срок, напоминание (создается в модуле reminders). За счект иерархии заметки должны строить в проекты с пошаговым планом. для объединение заметок в один проект связывающий группу заметок необходимо использовать групировку. заметки состоящие в групперовке будут объедененны в группу, у каждой группы будет название. Аналог папки. У заметок и папок будет такой атрибут как категория например личное, бизнес, работа, друзья, саморазвитие и тд. Категории можно добавлять, у каждой заметки или папки также может быть тег в самой заметке может несколько тегов прям в заметке, их нужно как-то обозначить чтобы это было популяроно в маркдаун файле. должен быть поиск по заметкам по словам. Заметки могут быть связаны друг с другом

Отвечает за:

- Notes;
- folders;
- categories;
- tags;
- поиск;
- связи;
- CRUD;
- структуру данных заметок.
