Назначение: зафиксировать концепцию первой версии Angel AI и последовательность её  
проектирования и разработки.

### 1 Angel AI 
персональная модульная AI-система, которая в будущем должна стать единой  экосистемой для получения, хранения, обработки и выдачи информации, а также выполнения действий от имени пользователя в рамках разрешений. V1 создаёт фундамент этой системы а именно организовывает работу пользователями с модулем заметки.

### 2. Ключевые требования V1  
• AI отделён от Core и работает через абстракцию LLM Provider; приоритет —локальная модель, API допускается как fallback. 
• Markdown Vault — синхронизированная человекочитаемая копия, доступная для Obsidian.   
• Масштабируемость: модульный монолит + workers + события, с возможностью позже выделить отдельные сервисы.  
• Permissions: AI не имеет неограниченной власти; опасные/значимые действия могут требовать подтверждения
### 3. Ключевые компоненты V1  
• Web интерфейсс — главный интерфейс управления системой и её модулями. 
• Telegram — дополнительный интерфейс для естественного языка, быстрых действий и уведомлений. работает также с системой.
• AI модуль - Является неотъемленной частью системы и выступает главным принимающим решения, принимаем запросы, принимает решения, вызывает инструменты (взаимодействия с другими модулями), работает с api.
• PostgreSQL — основное структурированное хранилище.  
• core - ядро системы связывает все в одно (возможно управляет напоминаниями внутри системы, например чтобы в опрделенное время вызвался ai агент прочитал это напоминание и что-то сказал пользователю)
