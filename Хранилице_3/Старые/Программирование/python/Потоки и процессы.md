Создание потока

```
orders_thread = threading.Thread(target=self.orders_sub, name='Отслеживание ордеров')  
orders_thread.start()
```

Поток это объект, у него можно вызывать методы. Чтобы вызывать методы потока прямо в потоке нужно к нему обратиться

```
threadind.currentThread().{Название метода или поля}
```

Методы:

```
threading.active_count() - количество активных потоков
threading.enumerate() - Выводит все потоки запущеные в данный момент
```


Потоки демоны:
Если поток будет демоном то он завершится когда завершится основной поток программы
Для работы потока с глобальной переменной нужно блокировать потоки методами lock rlock

```
locker = threading.Lock() - Создание блокиратора потоков
locker.acquire() - Блокировка потока
locker.release() - Разблокировка потока

with locker: - блокирует и разблокирует поток автоматически
	pass
```

Разблокировать поток может любой поток
При использовании RLock разблокировать поток может только поток который его заблокировал
Есть Local типа переменной но отдельной для каждого потока хз
