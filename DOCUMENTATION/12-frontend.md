# 12. Веб-интерфейс (frontend)

Vanilla JS SPA без сборщика. Файлы: `frontend/index.html`, `frontend/app.js`,
`frontend/style.css`. Раздаются тем же FastAPI-приложением (`/`, `/app.js`,
`/style.css`, `/static/*`). Интерфейс на русском.

## Каркас

- `index.html`: сайдбар с разделами + секции `#view-*` + `#toast` (уведомления).
- `app.js`:
  - `api(path, opts)` — обёртка fetch с JSON;
  - `showView(name)` — переключение разделов, вызов `load*`;
  - глобальные helper'ы `$`, `$$`, `esc`, `toast`;
  - словарь `RU` (переводы статусов/важности);
  - автообновление: dashboard каждые 15 c, stats — при включённом
    автообновлении каждые 5 c.

## Разделы (сайдбар)

| Раздел | view | Что внутри |
|--------|------|-----------|
| Обзор | dashboard | карточки-счётчики, ближайшие напоминания, состояние системы/LLM/Telegram |
| Заметки | notes | дерево (папки/подзаметки/категории), markdown-редактор, теги, важность, поиск |
| Напоминания | reminders | CRUD напоминаний, история срабатываний |
| AI-чат | ai | чат с агентом, вывод tool_calls и результата |
| Журнал | activity | таблица действий (время/участник/действие/модуль/инструмент/статус/длительность) |
| Статистика | stats | **логи**: фильтры, сводка, таблица с деталями, «что предшествовало», экспорт, очистка |
| Настройки | settings | AI/Ollama (провайдер, строка подключения, модель, тест, список моделей), Markdown (путь, синхронизация), разрешения AI |
| Система | system | здоровье, диспетчер/пул/планировщик, конфигурация модулей, пользователи Telegram и роли |

## Механика заметок

- Дерево с дедупликацией и «каноническим» размещением (`isChildOfNote`):
  заметка-потомок не дублируется в корне.
- Редактор: тулбар (B/I/K/E/Ссылка), предпросмотр, горячие клавиши
  `Ctrl+S` (сохранить), `Ctrl+B/I/K/E`, `Enter` (сохранить?/перенос),
  важность, теги-чипы.
- Поиск по заголовку и содержимому (клавиша Enter).

## Механика AI-чата

- Список сообщений, отправка `POST /ai/chat`, показ `text`; при
  `confirmation_id` — подсказка одобрить в «Система → Подтверждения».
- Ошибки LLM/агента выводятся как результат, а не паника.

## Статистика (логи) — детали

Фильтры: уровень (Все/Ошибки/DEBUG/INFO/WARNING/ERROR/CRITICAL), модуль/логгер,
поиск по тексту, даты «С/По». Кнопки: Применить, Сбросить, Автообновление
(галочка), Экспорт .txt, Очистить по фильтру.

Таблица: время (локальное), уровень (цветной бейдж), логгер, сообщение.
Клик по строке раскрывает детали: extra-поля, correlation/request/task id,
трейс исключения (`exc_text`).

Для ошибок — кнопка **«Контекст до»** / **«Что предшествовало»**: подгружает
последние записи до времени этой ошибки (`to_date=<ts>&order=desc&limit=15`,
перевёрнутые в хронологию) — удобно искать причину.

Пагинация: «Первая/Назад/Вперёд», счётчик записей и страниц.

## Соглашения фронтенда

- Никаких сборщиков; новые разделы = кнопка в сайдбаре + `#view-<name>` +
  функция `load*` + регистрация в `showView`.
- Инлайн-обработчики (`onclick`) в стиле проекта, функции вешать на `window`.
- Стили — HSL-переменные тёмной темы в `:root` (см. начало `style.css`).
