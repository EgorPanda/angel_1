# 15. Инструкция по пользованию

## Быстрый старт

1. (Один раз) Убедитесь, что установлен Python 3.14 и, если хотите локальный
   AI, — **Ollama** (см. `16-deployment.md`).
2. Запустите **`E:\angel\start.bat`** двойным кликом. Скрипт:
   создаст виртуальное окружение → установит зависимости (один раз) →
   применит миграции БД → откроет браузер `http://127.0.0.1:8000` → запустит
   сервер. Окно консоли НЕ закрывайте — на нём виден JSON-журнал.
3. В браузере откройте интерфейс и пользуйтесь разделами слева.

## Разделы интерфейса

### Обзор
Ключевые цифры: заметок, ближайших напоминаний, уведомлений, действий;
состояние системы, активный LLM, статус Telegram.

### Заметки
- Создавайте заметки в дереве: «+ Заметка», «+ Папка», «+ Категория».
- Редактор Markdown: кнопки форматирования, предпросмотр. Горячие клавиши:
  `Ctrl+S` сохранить, `Ctrl+B` жирный, `Ctrl+I` курсив, `Ctrl+K` ссылка,
  `Ctrl+E` код.
- Важность — низкая/средняя/высокая; теги добавляются чипами.
- Поиск по заголовку и содержимому (поле внизу дерева, Enter).

### Напоминания
- Добавление напоминания: текст + время + повтор (один раз/ежедневно/
  еженедельно/ежемесячно/ежегодно) + пояс.
- Сработавшие — в статусе «выполнено», история в карточке напоминания.

### Уведомления
Приходят с канала `web` (а также telegram, если бот подключён). Отмечайте
прочитанными.

### AI-чат
- Введите запрос — агент может сам (по разрешениям) создать заметку,
  напоминание, уведомление и т.д.
- Если действие требует подтверждения (режим `confirm`) — в ответе появится
  подсказка, одобрить/отклонить можно в «Система → Подтверждения».

### Журнал
Лента действий агента и системы (что, кто, когда, сколько длилось).

### Статистика (в т.ч. логи; «как проверять логи» — см. `14-logging.md`)
- Следите за ошибками: сводка «Ошибок за 24 ч», карточка «Последняя ошибка».
- Фильтруйте по уровню/логателю/дате/тексту, раскрывайте строки для трейса,
  у ошибок — «Что предшествовало», автообновление, экспорт в .txt.
- «Очистить по фильтру» — освободить БД от старых логов.

### Настройки
- **AI и Ollama**: провайдер (`ollama`, `local`, `api`), строка подключения
  (`URL API`, напр. `http://localhost:11434/v1`), модель. Кнопки:
  «Получить модели из Ollama» (подтянет установленные модели), «Проверить
  подключение», «Сохранить» (сразу перезапускает модуль ai). Сменить модель
  можно и после: выбрать из списка и «Сохранить».
- **Markdown-хранилище**: путь vault, кнопка «Синхронизировать сейчас».
- **Разрешения AI**: для каждого инструмента режим «Автоматически /
  С подтверждением / Запрещено».

### Система
- **Здоровье**: статусы всех компонентов (жёлтые/красные — смотреть деталь).
- **Диспетчер**: состояние, пул задач, планировщик, число пользователей.
- **Модули**: карточки модулей; «настройки ▾» раскрывает форму
  (сохранение + перезапуск). Здесь же — telegram токен/интервал, markdown,
  ai (полная конфигурация LLM).
- **Пользователи Telegram**: таблица; «Сделать админом»/«Снять права».
  Владелец (`angel`) защищён и понизить его нельзя.

## Telegram-бот

1. Создайте бота в `@BotFather`, скопируйте токен.
2. Вставьте токен в «Система → Модули → telegram → token», сохраните,
   перезапустите модуль.
3. Напишите боту в Telegram — пользователь создастся автоматически (роль
   `member`); в «Система» выдайте себе роль `admin`, если нужно больше прав.
4. Состояние бота — в «Здоровье» и в логах («Статистика», фильтр `telegram`).

## Работа с Markdown-хранилищем (vault)

- Заметки автоматически (по синхронизации) дублируются в папку vault в
  виде `.md`-файлов.
- Редактируйте файлы внешним редактором → «Настройки → Синхронизировать
  сейчас», изменения подтянутся в приложение.

## Частые вопросы

- **AI отвечает «404»?** Модель не установлена в Ollama. Откройте
  «Настройки → AI и Ollama», нажмите «Получить модели из Ollama», выберите
  установленную и «Сохранить».
- **Бот молчит.** Проверьте сеть (ошибка `getaddrinfo` в логах = нет доступа
  к api.telegram.org), токен, и здоровье `telegram`.
- **Ничего не сохраняется.** Смотрите «Статистика» → фильтр уровня ERROR —
  там будет причина (с трейсом и контекстом до).
- **Не работает локальный сервер из IDE?** Используйте `start.bat`, либо
  запускайте вручную: `cd backend` → `.venv\Scripts\python -m uvicorn
  app.main:app --port 8000`.
