# Angel AI — Документация проекта

Это самодостаточный пакет документации по приложению **Angel AI** (персональный
AI-ассистент: заметки, напоминания, уведомления, LLM-агент с инструментами,
Telegram-бот, синхронизация Markdown-vault, планировщик задач, веб-интерфейс).

Назначение пакета:

- дать новому разработчику ИЛИ нейросети-собеседнику полную картину:
  структура, архитектура, подход, ключевые знания и договорённости;
- служить источником правды при технических улучшениях и доработках;
- содержать инструкции по пользованию и по развёртыванию.

## Как пользоваться

1. Прочитайте `01-overview.md` и `02-architecture.md` — это даст каркас.
2. Далее по роли:
   - «хочу понять БД/модули/AI» → `04-database.md`, `05-modules.md`, `06-ai-agents.md`;
   - «хочу проверить логи / ошибки» → `14-logging.md`;
   - «нейросеть, улучшай это» → скормить файлы пакета в порядке номеров;
   - «хочу запустить/развернуть» → `15-user-guide.md`, `16-deployment.md`;
   - «хочу добавить код» → `17-development-guide.md`.

## Правило сопровождения (важно!)

**Любое изменение кода приложения сопровождается обновлением этой документации.**
Это правило также зафиксировано в `E:\angel\AGENTS.md`, чтобы помощник
(агент) всегда следовал ему. Список фактов, которые обязательно должны быть
актуальны: эндпоинты, таблицы БД, поля конфигурации модулей, инструменты,
переменные `.env`, разделы интерфейса, шаги развёртывания.
